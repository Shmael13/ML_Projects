# Supervised Learning Algorithms

This repository contains hands-on implementations of key supervised learning algorithms using Python and scikit-learn. Each subdirectory focuses on a specific algorithm or family of algorithms

## Directory structure

- **Boosting**
  - Contains an example of the AdaBoost learning ALgorithm
  - Demonstrates how weak learners can be combined to create powerful ensemble models

- **KNN**
  - Implements the k-Nearest Neighbors classifier.
  - Shows parameter tuning and distance metrics for effective nearest-neighbor classification.

- **Linear_and_Logistic_Regression**
  - Provides implementations of linear regression for regression tasks
  - Includes logistic regression for binary and multiclass classification problems

- **Neurons**
  - Explores simple artificial neurons (perceptrons) and multilayer feedforward neural networks
  - Demonstrates how neural models learn decision boundaries for classification tasks

- **Trees**
  - Covers decision tree classifiers, regressors and random forest
  - Includes visualizations of tree structures
