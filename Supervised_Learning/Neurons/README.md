# Custom Single & Multi-Layer Neurons

This directory contains Notebooks with custom implementations of single-layer and multi-layer neurons (perceptrons), built from scratch without high-level deep learning libraries.

---

**Single-Layer Neuron (Perceptron):**
A single-layer neuron is the simplest form of a neural network — it takes a weighted sum of input features, adds a bias, applies an activation function (like a step or sigmoid), and produces an output. It can only learn to separate data that’s linearly separable, making it suitable for simple binary classification tasks.

**Multi-Layer Neuron (Multi-Layer Perceptron, MLP):**
A multi-layer neuron network adds one or more hidden layers between the input and output. Each hidden layer contains multiple neurons that apply nonlinear activation functions, allowing the network to learn complex, non-linear patterns in the data. Multi-layer perceptrons can approximate arbitrary functions and solve problems single-layer perceptrons cannot — like the classic XOR problem.
